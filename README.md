# IntelliAttend - SmartBoard portal

The SmartBoard portal is a specialized web interface designed for classroom display. It generates dynamic QR codes for attendance tracking and provides real-time feedback on students checking in.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Modern Web Browser

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

## 📁 Repository Structure
- Source code for the vanilla JavaScript web portal.
- Static assets and QR generation logic.
- `docs/`: Technical documentation.
