# Machine Learning — Course Syllabus

## Course Code: CSE-AIML 305
## Instructor: Dr. Arjun Mehta
## Semester: VI | Credits: 4

---

### Module 1: Foundations of Machine Learning

- **Week 1-2:** Introduction, Types of ML (Supervised, Unsupervised, Reinforcement)
- **Week 3:** Probability & Statistics review, Bayes Theorem
- **Week 4:** Linear Algebra essentials for ML

### Module 2: Supervised Learning

- **Week 5-6:** Linear Regression, Polynomial Regression
- **Week 7:** Logistic Regression, Decision Trees
- **Week 8:** Support Vector Machines, Kernel Trick
- **Week 9:** Ensemble Methods — Random Forest, Gradient Boosting

### Module 3: Unsupervised Learning

- **Week 10:** K-Means Clustering, Hierarchical Clustering
- **Week 11:** Principal Component Analysis (PCA)
- **Week 12:** t-SNE, DBSCAN

### Module 4: Neural Networks & Deep Learning

- **Week 13:** Perceptron, Multi-Layer Networks, Backpropagation
- **Week 14:** CNNs for Image Classification, RNNs for Sequence Data
- **Week 15:** Transfer Learning, Fine-tuning pre-trained models

### Module 5: Ethics & Deployment

- **Week 16:** Bias in ML, Fairness, Explainability (SHAP, LIME)
- **Week 17:** Model deployment — Flask APIs, ONNX, TensorFlow Serving
